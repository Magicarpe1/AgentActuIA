## Outils à tester

### Remotion ajoute le motion blur et la transcription locale
La v4.0.546 intègre un vrai flou de mouvement sur les transitions et une commande `npx remotion whisper` pour transcrire en local — de quoi peaufiner la vidéo de présentation en motion design d'une salle de jeux interactifs. [GitHub · remotion-dev/remotion](https://github.com/remotion-dev/remotion/releases/tag/v4.0.546)

### ffmpeg-skill donne 42 outils de montage vidéo à Claude Code, Cursor et Codex
Un serveur MCP qui découpe, sous-titre, recadre, normalise le son et exporte par plateforme, tout en local sans clé API : pratique pour produire des vidéos sans repasser par un éditeur classique. [GitHub · kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill)

### CROO Skill branche Claude Code et Codex sur 4 000 agents IA
Une skill qui permet d'appeler directement une flotte de 4 000 agents spécialisés depuis le terminal, sans multiplier les intégrations une par une. [BigGo Finance](https://news.google.com/rss/articles/CBMidkFVX3lxTE5hWkI1NVFSZ24yVVN5MGVmN0NnMm5ZOFBMUDEtdUo2R3k3UWlWN00wNVlZZ211bENfbkV2UXZ3TDU5SF96TW1BNU16SFM2cXpxUzV1WFV2LXJWN3RwelNGc1pFVmh6S2RqY09TdEZSUEgzeFBMSlE?oc=5)

### chrome-devtools-mcp met Chrome DevTools dans les mains de l'agent de code
Un serveur MCP qui laisse l'agent inspecter, déboguer et piloter Chrome directement : utile pour déboguer une appli mobile ou une interface web sans changer d'outil. [GitHub · ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)

### Astryx, un design system open source pensé pour être piloté par un agent
Entièrement personnalisable et conçu pour qu'un agent de code le manipule directement, il peut servir de base pour accélérer l'interface d'une appli métier. [GitHub · meta/astryx](https://github.com/meta/astryx)

### Plannotator centralise le suivi des agents IA sur un projet
Un espace pour cadrer les tâches, annoter le code généré et renvoyer du feedback aux agents en un clic : pratique pour jongler entre plusieurs projets en parallèle. [GitHub · backnotprop/plannotator](https://github.com/backnotprop/plannotator)
